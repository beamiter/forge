# Shared core refresh: 2026-11-13

Forge moves its production root `jterm_core` dependency from
`598f15808086dbea14d56fc1b86e77b6cb2e3201` to
`1ebfe4573d43c1b6de0332476cfea75f42899a96`.

## Scope and behavior review

Forge continues to use GTK/VTE. This update does not adopt the shared
`jterm-engine` parser and is not five-host protocol conformance evidence.
The root library's production changes between these revisions are limited to:

- Codex app-server launch scopes: detect the systemd version and explicitly
  disable environment expansion on systemd >= 254, preserving the literal shell
  gate payload. Older versions use their literal default. The version probe is
  bounded to two seconds and fails closed on unrecognized, failed, or timed-out
  probes. Failed scope attachment diagnostics are bounded/nonblocking.
- Screen replay resize: equivalent tab-stop iteration for the current Clippy.

The root dependency manifest is unchanged and review found no public API break.
The systemd probe's fail-closed behavior is intentional, not a no-op repin.

## Reproducibility and local checks

All production and harness pins, Flatpak source references, Nix source hash,
source receipts, adapter metadata, and deterministic audit archive are updated
together. The NAR calculation reproduces the previous committed hash before
calculating the new hash. Independent review compared all 305 archive files to
the pinned source revision.

The pin guard now checks the production receipt revision and repository, its
NAR SRI shape, and agreement with the Nix output hash. All 20 guard tests pass,
including stale-receipt, stale-hash, and malformed-hash regression cases.
Host (27 files) and process (8 files) bundle guards pass. Locked Cargo metadata,
mission acceptance harness tests, standalone files-follow, search lifecycle,
pane lifecycle, tab selection, PTY resize, and real PTY admission checks pass
using Rust 1.100.0. Three launch-scope tests also pass: literal payload,
old/new systemd version policy, and bounded fail-closed probes. These checks do not substitute for the desktop release gate.

## Remaining release evidence

Local GTK4, libadwaita and VTE development packages are unavailable; no local
native GUI build or visual acceptance is claimed. Nix/Flatpak native builds and
real systemd scope startup require their appropriate native environments.
Remote CI for the resulting Forge commit must be checked before declaring the
migration fully accepted.
